## Overview

Simple Layout is made for small setups, like a home lab with a few hosts. It has a top bar, a Home screen with a card for each host, short host and credential forms, and a short Settings screen. You can switch to another layout in Settings, Appearance.

Read the [docs](https://docs.termix.site/plugins/simple-layout) to learn how it works.

<br />

## Features

- Top bar with tabs, search and settings
- Home screen with a card for each host
- Short host and credential forms
- Only the settings most people need
- Search window
- Mobile bottom bar

## Support

Bugs and ideas for Simple Layout go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Simple-Layout/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Simple-Layout/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
